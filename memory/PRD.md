# Continents of Delarom — Product Requirements

## Original Problem Statement
A fantasy-world exploration / roleplay site set in the "Continents of Delarom" universe. Members register, create characters, roleplay at locations (T1-style), interact with an AI Quest Master, and explore an interactive map.

## Core Personas
- **Members**: roleplayers who write actions and interact with AI-driven NPCs in shared locations.
- **Admins / Moderators**: manage applications, users, IP bans, locations, NPCs, scene events, diplomacy and world events.
